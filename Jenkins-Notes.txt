Jenkins
----------

Jenkins is free and opensource software.

Jenkins developed using java language.

Jenkins is used to automate project build and deployment process.

Using Jenkins we can implement CI CD.
continuous integration and continuous deployment.

-----------------------------------

create docker container

select pipeline (give job name)


Jenkins pipeline create by two ways script approach(groovy lang)  and declarative approach(plain English)

----------------------------------------------------------------------
 pipeline {

	agent any

	tools{
		'mvn'
		
	}
 
	stages {
		stage('git clone'){

			steps{
				git 'url'
			}

		}
		stage('mvn build'){
			steps{
				sh 'mvn clean package'
			}
		}
		stage('docker image'){
			steps{
				sh 'docker build -t <imgname> .'
			}
		}
		stage{'deployment'){
			steps{
				
				sh 'docker run -d -p 9090:8080 <container name> <img name>'
			}
		}
	}


 }
